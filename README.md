## 📖 About The Project

**HyFun Foods** is a fully responsive **corporate/business website** built for a global frozen-potato-snacks brand. The site showcases the brand's story, product range, global partnerships, and export network through a clean, modern, and animated UI — built entirely with **HTML, CSS, and JavaScript**.

This project was built to sharpen real-world skills in **semantic HTML structuring, responsive CSS layouts, JavaScript interactivity, and multi-page website architecture**.

> 💡 *"At HyFun, we believe in spreading health & happiness to as many countries as we can."*

## 🚀 Getting Started

Run this project locally in a few simple steps:

```bash
# 1. Clone the repository
git clone https://github.com/shahrishabh1513-jsk/hyfun-foods-corporate-website.git

# 2. Navigate into the project directory
cd hyfun-foods-corporate-website

# 3. Open index.html in your browser
#    (or use the Live Server extension in VS Code)
```

No build tools, dependencies, or installations required — it's a pure **HTML/CSS/JS** project. Just open and explore! 🎉
